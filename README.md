# FeastWineAllGone / 亿宴酊蒸

A Minecraft Forge 1.20.1 mod that expands **Touhou Little Maid** with autonomous dining, drinking, food interaction, nighttime wine stealing, meal progression, fruit tasting, maid-specific behavior settings, and related compatibility features.

> Required Notice: Copyright © 2026 BraisedChimiRice (黄焖基米饭). Original project: FeastWineAllGone / 亿宴酊蒸.

## Status

This repository is the public source repository for FeastWineAllGone.

- Minecraft: 1.20.1
- Forge: 47.x
- Java: 17
- Main dependency: Touhou Little Maid
- Additional integrations include Kaleidoscope Tavern, Kaleidoscope Cookery, Farmer's Delight, and other supported food/drink mods.

## Building

This project targets Java 17 and Forge 1.20.1.

Third-party dependency JARs are not redistributed in this repository. Development dependencies must be obtained from their respective official distribution sources and placed/configured as required by the Gradle build.

```bash
./gradlew build
```

On Windows:

```bat
gradlew.bat build
```
